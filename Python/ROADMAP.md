# Feuille de route — 12 semaines

## Phase 1 — Fondamentaux Python

### Semaine 1 : syntaxe et logique
Installation et vérification de Python · exécution de scripts depuis le terminal · `print()`, `input()`, commentaires · variables, constantes par convention, affectations · `int`, `float`, `str`, `bool` · conversion des types · opérateurs arithmétiques, de comparaison et logiques · `if` / `elif` / `else` · `for`, `while` · `range()`, `break`, `continue`.
**Projet :** calculatrice en ligne de commande avec validation des entrées.

### Semaine 2 : collections et fonctions
Listes, tuples, ensembles, dictionnaires · indexation, tranches, parcours · ajout, modification, suppression · méthodes de chaînes · `def`, paramètres, `return` · arguments par défaut · portée des variables · compréhensions de listes · décomposition en petites fonctions.
**Projet :** gestionnaire de notes d'étudiants (moyennes, classement, recherche).

### Semaine 3 : fichiers et exceptions
Lecture et écriture de fichiers · `with open()` · UTF-8 · JSON et CSV · `try` / `except` / `else` / `finally` · exceptions courantes · validation des saisies · lecture des messages d'erreur.
**Projet :** gestionnaire de dépenses en terminal avec sauvegarde JSON.

## Phase 2 — Python intermédiaire

### Semaine 4 : programmation orientée objet
Classes et objets · attributs, méthodes · `__init__`, `self` · encapsulation, propriétés · héritage · composition · méthodes spéciales · choisir entre fonctions et classes.
**Projet :** gestion de produits, de stock et de commandes.

### Semaine 5 : modules et code propre
Modules, imports · packages, structure de projet · `venv` · `pip` · annotations de types · PEP 8 · docstrings · séparation des responsabilités · variables d'environnement, `.gitignore`.
**Projet :** découper le gestionnaire de dépenses en modules.

### Semaine 6 : algorithmique et tests
Recherche, filtrage · comptage, agrégation · tri · complexité O(n) et O(n²) · récursivité · assertions · `unittest`, puis `pytest` · débogueur et points d'arrêt.
**Projet :** bibliothèque de fonctions de calcul avec tests automatisés.

## Phase 3 — Outils professionnels

### Semaine 7 : Git et GitHub
`git init`, `status`, `add`, `commit` · `git log` · branches, fusion · conflits simples · dépôt distant GitHub · README, `.gitignore` · commits clairs.
**Projet :** publier un projet Python propre sur GitHub.

### Semaine 8 : SQL et bases de données
Modélisation relationnelle · clés primaires et étrangères · types SQL · `SELECT`, `INSERT`, `UPDATE`, `DELETE` · `WHERE`, `ORDER BY`, `GROUP BY`, `JOIN` · contraintes, transactions · SQLite avec Python · notions de PostgreSQL · requêtes paramétrées contre l'injection SQL.
**Projet :** gestion de stock sur une vraie base de données.

## Phase 4 — Backend Python

### Semaine 9 : HTTP et API REST
Client et serveur · HTTP et HTTPS · GET, POST, PUT, PATCH, DELETE · codes de statut · JSON, en-têtes · paramètres de chemin et de requête · `requests` / `httpx` · validation · ressources REST.
**Projet :** consommer une API publique en gérant les erreurs.

### Semaine 10 : première API FastAPI
Installation, lancement · routes · paramètres · modèles Pydantic · validation · codes HTTP, exceptions · OpenAPI · CRUD · persistance SQLite ou PostgreSQL · tests des endpoints.
**Projet :** API CRUD de produits.

### Semaine 11 : architecture et sécurité
Routes, services, accès aux données · dépendances · configuration par l'environnement · authentification et autorisation · hachage des mots de passe · rôles, permissions · migrations · tests unitaires et d'intégration · cas limites.
**Projet :** ajouter à l'API les utilisateurs, les rôles et les tests.

### Semaine 12 : projet final et déploiement
API de gestion de stock : utilisateurs et authentification, produits et catégories, mouvements d'entrée et de sortie, contrôle des quantités, historique, base relationnelle, validation, tests, documentation, configuration de production, Docker, déploiement de démonstration. Construite fonctionnalité par fonctionnalité.
