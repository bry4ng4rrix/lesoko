# Formation Python — de zéro à une API FastAPI

Parcours personnel de 12 semaines (2 à 3 h par jour, 6 jours par semaine) pour devenir un développeur Python autonome.

**Principe :** comprendre avant de copier. L'IA joue le rôle de formateur : elle explique, donne des indices et corrige. Elle n'écrit pas les exercices à ma place.

## Organisation du dépôt

| Élément | Contenu |
|---|---|
| `ROADMAP.md` | Programme des 12 semaines |
| `PROGRESSION.md` | Où j'en suis : jour actuel, résultats, points à revoir |
| `NOTES.md` | Notions à retenir et erreurs importantes |
| `LESSONS/` | Cours jour par jour ([index](LESSONS/README.md)) |
| `EXERCISES/` | Mes solutions, par semaine et par jour |
| `PROJECTS/` | Projets pratiques de fin de semaine |

- Python 3.14
