# Exercices D04 — Hiérarchie visuelle et mise en page

Livrables dans `DESIGN/TRAVAUX/D04/`. Cours : [`LESSONS/D04`](../LESSONS/D04-hierarchie-mise-en-page.md)

## Exercice 1 — Plisser les yeux (facile, 20 min)

Prends 3 captures d'écran d'apps différentes. Floute-les (GIMP : Filtres → Flou
gaussien, rayon 10 ; ou plisse les yeux).

Dans `flou.md`, pour chacune : les 3 éléments qui ressortent, dans l'ordre ; ce
que l'écran **veut** mettre en avant (selon toi) ; l'ordre correspond-il ?

## Exercice 2 — Réparer une carte (intermédiaire, 30 min)

Voici une carte de commande, où tout est au même niveau :

```
┌────────────────────────────────────┐
│ Commande : 1042                    │
│ Date : 23/10/2026 14:32            │
│ Statut : Prête à retirer           │
│ Articles : 3                       │
│ Total : 37500 Ar                   │
│ [Voir le détail] [Annuler]         │
└────────────────────────────────────┘
```

Dans `carte-commande.md` :
1. Classe les informations par importance pour **un client qui vient vérifier
   si sa commande est prête**.
2. Redessine la carte en appliquant **au moins 3 leviers** et les principes de proximité.
3. Explique chaque changement.

## Exercice 3 — Hiérarchie des 5 écrans Tsena (intermédiaire, 1 h)

Reprends tes wireframes D03. Pour chaque écran, écris l'**ordre d'importance**
des éléments, puis révise le wireframe pour que la hiérarchie corresponde.
Indique les **groupes** (proximité) et les espacements internes et externes.

## Exercice 4 — Programmation (quand tu maîtrises `Row`/`Column`, semaine 6)

Dans un projet Flutter d'essai, reproduis **ta** carte de commande de
l'exercice 2 sous forme de widget `CarteCommande`.

Contraintes :
- aucune taille de police en dur : uniquement `Theme.of(context).textTheme` ;
- texte secondaire en `onSurfaceVariant` ;
- espacements internes 4-8, externes 16 ;
- teste avec un numéro de commande très long et un écran de 320 de large : rien ne déborde.

## Défi — La même information, trois intentions (sans solution)

Le même produit (nom, prix, stock, note client, promotion) est affiché dans 3 contextes :
1. une **liste** de recherche, où l'on compare vite ;
2. le **panier**, où l'on vérifie la commande ;
3. un **tableau de bord** de la gérante, où l'on surveille le stock.

Dessine les 3 versions et explique pourquoi la hiérarchie change.
