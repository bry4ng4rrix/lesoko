# Exercices D08 — Design tokens et design system

Livrables : documentation dans `DESIGN/TRAVAUX/D08/`, code dans `PROJECTS/tsena/`.
Cours : [`LESSONS/D08`](../LESSONS/D08-design-tokens-design-system.md)

Prérequis Flutter : semaine 6 terminée, et les classes Dart (semaine 3).

## Exercice 1 — Étudier un design system public (facile, 30 min)

Parcours **un** design system parmi Material 3, Polaris (Shopify) ou Carbon (IBM).
Dans `etude-ds.md` : comment sont organisés les tokens ? Comment est documenté
**un** composant (ex. le bouton) ? Qu'est-ce que tu reprendrais pour Tsena ?

## Exercice 2 — Tokens en trois niveaux (intermédiaire, 45 min)

Remplis le modèle [`RESSOURCES/modele-tokens.md`](../RESSOURCES/modele-tokens.md)
pour Tsena (`tokens.md`) : primitifs, sémantiques (clair + sombre) et, si
utile, de composant. Reprends tes travaux D05, D06 et D07.

**Critère** : aucun token sémantique ne porte un nom d'apparence (`vert`, `gros`).

## Exercice 3 — Le thème Flutter (intermédiaire, 1 h 30)

1. Crée le projet : `flutter create --org mg.formation --platforms=android,linux PROJECTS/tsena`.
2. Crée `lib/core/design_system/` avec `tokens.dart` et `theme.dart`.
3. Implémente `CouleursApp` (`ThemeExtension`) avec **tes** couleurs succès et
   avertissement, **sans recopier** le cours : écris-la, puis compare.
4. Configure dans le thème : `cardTheme`, `filledButtonTheme`,
   `inputDecorationTheme`, `appBarTheme`.
5. Crée un écran **Catalogue du design system** qui affiche : les rôles de
   couleur, les styles de texte, les tokens d'espacement (des barres de
   largeur 4, 8, 16…) et les rayons.

**Critères** : `flutter analyze` → aucun problème ; basculer en mode sombre ne
casse rien ; `grep -rn "Color(0x" lib/` ne trouve des couleurs **que** dans `tokens.dart`.

## Défi — Changer d'identité en 5 minutes (sans solution)

Chronomètre-toi : change l'identité de Tsena (couleur, police, rayons) pour un
autre client (ex. une pharmacie). Combien de fichiers as-tu modifiés ? Si plus
de 2, qu'est-ce qui a échappé au système, et comment le corriger ?
