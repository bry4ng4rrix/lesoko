# Exercices D09 — Composants et états

Livrables : `DESIGN/TRAVAUX/D09/` + code dans `PROJECTS/tsena/lib/core/design_system/composants/`.
Cours : [`LESSONS/D09`](../LESSONS/D09-composants-etats.md)

## Exercice 1 — Inventaire des composants (facile, 30 min)

Parcours tes wireframes et maquettes Tsena. Dans `inventaire.md`, liste
**chaque composant** différent (bouton principal, carte produit, sélecteur de
quantité, badge de stock, élément de panier, état vide…), avec : le nombre
d'écrans où il apparaît, ses variantes et ses états nécessaires.

## Exercice 2 — Spécifier un composant (intermédiaire, 30 min)

Pour **CarteProduit**, rédige la spécification (`carte-produit.md`) : rôle,
quand l'utiliser et quand ne pas l'utiliser, paramètres (comme un constructeur
Flutter), variantes, états (normal, pressé, rupture, chargement/squelette),
accessibilité (libellé lu par TalkBack, cible tactile).

## Exercice 3 — Programmation : la bibliothèque (avancé, 2 h)

Implémente dans `composants/` :

1. `BoutonAction` : variantes principal / tonal / destructif ; état de chargement.
   Écris-le **sans regarder** le cours, puis compare.
2. `SelecteurQuantite` : `– n +`, minimum 1, maximum = stock, boutons désactivés aux bornes, `tooltip` sur chaque bouton.
3. `CarteProduit` : selon ta spécification, avec un état `enRupture`.
4. `EtatVide` : illustration (icône), titre, message, action optionnelle.
5. `EtatErreur` : message + bouton « Réessayer ».

Ajoute-les tous, avec **toutes** leurs variantes et tous leurs états, à l'écran
catalogue du design system (D08).

**Critères** : aucun composant ne contient de couleur ni de taille en dur ;
les états de chargement bloquent l'action ; tout est lisible en mode sombre et
avec le texte à 200 %.

## Exercice 4 — Adaptatif (facile, 20 min)

Dans un écran Réglages, ajoute un `Switch.adaptive` et un dialogue
`showAdaptiveDialog`. Lance avec `flutter run -d linux`, puis forcez la
plateforme iOS (`theme: ThemeData(platform: TargetPlatform.iOS)`) et compare.

## Défi — Le bouton « Payer » parfait (sans solution)

Conçois et code le bouton de paiement de Tsena. Il doit gérer : panier vide,
montant affiché dans le libellé, paiement en cours, échec (avec réessai) et
succès. Il doit aussi empêcher le double paiement **même si** l'utilisateur
touche deux fois très vite. Documente les états dans un tableau.
