# Formation Dart & Flutter

Parcours personnel de 20 semaines pour devenir développeur Flutter autonome :
concevoir des interfaces mobiles (UI/UX, design system, maquettes), les
reproduire fidèlement en Flutter, puis tester, déboguer, maintenir et déployer
des applications Android (et comprendre iOS).

## Rythme

- 2 à 3 heures par jour, 6 jours par semaine.
- Une séance = cours + exemples + exercices + évaluation.
- On ne passe pas à la suite tant que les prérequis ne sont pas maîtrisés.

## Organisation du dossier

| Élément          | Contenu                                              |
|------------------|------------------------------------------------------|
| `ROADMAP.md`     | Parcours complet sur 20 semaines                     |
| `PROGRESSION.md` | Suivi des compétences, exercices, évaluations        |
| `NOTES.md`       | Notions importantes et erreurs à retenir             |
| `LESSONS/`       | Cours, classés par semaine et séance                 |
| `EXERCISES/`     | Énoncés d'exercices (et plus tard les tests)         |
| `DESIGN/`        | Wireframes, spécifications, design tokens            |
| `PROJECTS/`      | Projets pratiques                                    |

## Exécuter un fichier Dart

```bash
dart run EXERCISES/semaine-01/seance-01/ex01_presentation.dart
```
